# VIGILANT Consulting Website Bundle

This bundle includes the updated VIGILANT homepage as a ready-to-drop Next.js App Router page with Tailwind CSS styling.

## Included
- `src/app/page.tsx`
- `src/app/layout.tsx`
- `src/app/globals.css`
- `package.json`
- `tsconfig.json`
- `next-env.d.ts`

## Setup
```bash
npm install
npm run dev
```

Open `http://localhost:3000`

## Notes
- `lucide-react` is already included in `package.json`
- If you already have a project, replace your existing `src/app/page.tsx`, `src/app/layout.tsx`, and `src/app/globals.css` with the versions from this bundle
